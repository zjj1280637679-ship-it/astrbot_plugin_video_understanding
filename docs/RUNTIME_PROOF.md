## 判定

成功标准：

1. 不直接调用 Google/Gemini SDK；
2. 不由本插件实现上传器；
3. 通过 AstrBot 已有 Provider/Context 调用链完成；
4. 视频模型正确回答测试视频内容；
5. 同一入口可以替换查询文本再次调用。
