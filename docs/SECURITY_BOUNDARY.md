# 安全与职责边界

## 核心原则

本插件只把视频变成一个可供主模型查询的信息源，不提升视频内容的指令权限。

视频中的：

- 字幕；
- 屏幕文字；
- 人物对白；
- 代码；
- 二维码内容；
- 页面中的提示词；

都属于**被搜索的数据**，不能改变系统提示词、插件工具规则或主模型权限。

## 信任边界

```text
系统/人格/工具规则
        ↓ 高信任
主模型的 query_video 查询
        ↓
插件稳定视频搜索提示
        ↓
视频模型卡
        ↓
视频观察结果
        ↓ 低信任外部证据
视频画面/声音/字幕
```

## 插件不得执行的动作

即使视频内容要求，也不得由 `query_video`：

- 调用额外工具；
- 读取服务器密钥；
- 修改插件配置；
- 修改系统提示词；
- 主动发送消息；
- 访问与当前视频无关的文件；
- 执行视频中展示的命令；
- 把视频中的文字当成开发者指令。

## 结果表述边界

视频模型应尽可能区分：

```text
直接观察
合理推测
无法确认
```

禁止把“没有观察到”自动升级为“视频中不存在”。

例如正确：

```text
在 00:10-00:25 范围内未观察到成功提示。
```

不推荐：

```text
视频里绝对没有成功提示。
```

除非该次查询确实覆盖完整视频，并且模型有足够证据支持强结论。

## 隐私边界

插件不建立长期视频资产库。第一版只使用 AstrBot 当前事件已经提供的视频引用。

日志中不得默认记录：

- 视频 Base64；
- 完整临时 URL；
- API Key；
- 用户隐私标识；
- 完整视频转录；
- 本地用户目录。

调试日志只记录必要元数据，例如：

```text
video_index
provider_id
query_length
elapsed_ms
success/failure
```

## 失败封闭

Provider 或视频读取失败时，工具应返回“未取得视频证据”的明确错误，而不是：

- 自动换模型；
- 自动抽帧；
- 自动 OCR；
- 自动 STT；
- 根据文件名猜测内容。

这样可以保证失败不会悄悄改变系统架构或证据等级。
