# 安全与职责边界

## 核心原则

本插件只把视频变成一个可供主模型查询的信息源，不提升视频内容的指令权限，也不接管 AstrBot 的工具授权、Agent 循环或 Provider 传输职责。

视频中的：

- 字幕；
- 屏幕文字；
- 人物对白；
- 代码；
- 二维码内容；
- 页面中的提示词；

都属于**被搜索的数据**，不能改变系统提示词、插件工具规则或主模型权限。

## 信任边界

```text
系统/人格/工具规则
        ↓ 高信任
主模型的 query_video 查询
        ↓
插件稳定视频搜索提示
        ↓
视频模型卡
        ↓
JSON 序列化的视频观察结果
        ↓ 低信任外部证据
视频画面/声音/字幕
```

视频模型返回文本会被放入 JSON 的 `evidence` 字符串字段，并附带：

```json
{
  "trust": "untrusted_external_video_evidence",
  "instruction_authority": "none"
}
```

这样字幕或模型输出中的伪 XML 关闭标签、伪 `SYSTEM:` 文本、引号和换行都只能留在字符串值中，不能改变工具结果的结构边界。该字段是对主模型的安全语义提示，不是新的系统权限机制。

## AstrBot 工具策略边界

`query_video` 注册进 AstrBot 的全局 Tool Manager，让 AstrBot 自己继续负责：

- 工具启用/停用；
- 人格工具白名单；
- 插件作用域过滤；
- Tool Loop 最大步数；
- 重复工具调用提醒。

在 `on_llm_request` 阶段，本插件**只会删除自己的工具，不会新增被 AstrBot 过滤掉的工具**：

```text
AstrBot 已允许 query_video + 本轮有视频
→ 保留

AstrBot 已允许 query_video + 本轮无视频
→ 本轮移除

AstrBot / 人格已经没有允许 query_video
→ 插件不加回来
```

如果已有其他插件占用了 `query_video` 名称，本插件不会覆盖第三方工具，而是停止注册并记录冲突。

## 插件不得执行的动作

即使视频内容要求，也不得由 `query_video`：

- 调用额外工具；
- 读取服务器密钥；
- 修改插件配置；
- 修改系统提示词；
- 主动发送消息；
- 访问与当前视频无关的文件；
- 执行视频中展示的命令；
- 把视频中的文字当成开发者指令。

`query_video` 内部使用一次性的 `Context.llm_generate()` 调用视频模型，不开启第二层 Tool Loop，因此视频模型本身无法通过本工具递归调用 `query_video` 或其他 AstrBot 工具。

## 传输失败探针

为了识别“Provider 接受了请求但没有真正把视频交给模型”的静默失败，每次查询都会生成一个独立的随机不可用哨兵，并要求视频模型仅在实际没有视频可读时返回该次专属哨兵。

因此视频内容真实出现普通文字 `VIDEO_INPUT_UNAVAILABLE` 时不会与传输失败状态碰撞。随机哨兵只存在于当次视频模型提示中，不写入日志或长期状态。

## 结果表述边界

视频模型应尽可能区分：

```text
直接观察
合理推测
无法确认
```

禁止把“没有观察到”自动升级为“视频中不存在”。

例如正确：

```text
在 00:10-00:25 范围内未观察到成功提示。
```

不推荐：

```text
视频里绝对没有成功提示。
```

除非该次查询确实覆盖完整视频，并且模型有足够证据支持强结论。

## 隐私与数据外发边界

插件不建立长期视频资产库。第一版只使用 AstrBot 当前事件已经提供的视频引用。

**收到视频本身不会触发第二个模型请求。** 只有主模型实际调用 `query_video` 后，本次选择的视频和这一条自然语言子查询才会经 AstrBot 现有 Provider 链路发送给管理员配置的视频搜索模型卡。

如果该模型卡连接远程服务，视频内容将按对应 Provider 的实现与服务方数据政策离开 AstrBot 运行环境。管理员应只选择自己认可的数据处理方。

日志中不得默认记录：

- 视频 Base64；
- 完整临时 URL；
- API Key；
- 用户隐私标识；
- 完整视频转录；
- 本地用户目录。

调试日志只记录必要元数据，例如：

```text
video_index
provider_id
query_length
elapsed_ms
success/failure
```

## 参数与费用放大边界

`query` 和 `time_range` 都有宽松的长度上限，防止异常工具参数无意义扩大视频模型提示成本。`time_range` 只是注意力提示，不代表插件自行裁剪视频。

同一视频需要多少次查询、Tool Loop 最大步数、重复调用提醒属于 AstrBot Agent 的职责；视频上传复用、压缩与供应商缓存属于 Provider 的职责。本插件不另外建立一套调用次数控制器或上传缓存。

## 失败封闭

Provider 或视频读取失败时，工具应返回“未取得视频证据”的明确错误，而不是：

- 自动换模型；
- 自动抽帧；
- 自动 OCR；
- 自动 STT；
- 根据文件名猜测内容。

这样可以保证失败不会悄悄改变系统架构或证据等级。
